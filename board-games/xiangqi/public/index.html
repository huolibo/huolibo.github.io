一起来下棋
离线使用
首次联网打开，等待右上角显示“离线已就绪”。可从 Safari 分享菜单或 Chrome 菜单添加到主屏幕。缓存被系统清理后需要重新联网下载。
一次扫码快捷联机
双方保持联网并接入同一 Wi-Fi 或热点。创建方选择“创建快捷邀请”，另一方用手机相机扫描链接，或在本页“加入快捷对局”中扫描、粘贴邀请。无需回传回应码。使用 PeerServer Cloud 自动交换配对信息，棋步通过双方直连，AI 在本机计算。公共服务不可用时可改用离线互扫。
附近对战 · 离线备用
使用 Safari 或 Chrome 打开页面。双方连接同一 Wi-Fi 或热点，由红方创建、黑方加入，再由红方读取黑方的回应码。黑方确认规则后开始。二维码较长时会分成多页，需要逐页扫描。也可以复制完整连接码。
再来一局
结束后点“再来一局”。同机直接开局；联机需对方同意，沿用规则和执棋方，无需重新扫码，AI 配额按新局恢复。邀请超时或断线取消。需留存上一局时，请先导出棋谱。
断线与恢复
连接中断时暂停走棋，保留棋局。红方选择“红方重连”，黑方选择“黑方重连”，重新交换连接码，双方核验历史后继续。请不要点“新开一局”。建议定期导出棋谱。
双方同意才悔棋
每次申请撤回自己最近一手；对方已经应了一手时，一并撤回两手。对方须在 30 秒内同意，等待期间暂停走棋和 AI。拒绝、超时或断线均取消请求，保留原局面。AI 已用次数不退还；已结束的棋局不能悔棋。同机模式由对方接过设备确认。
AI 的 30 秒
默认未配置 AI，点击分析提示“AI 暂不可用”，不扣次数。可在“AI 设置”中选择内置本地引擎，无需 API 密钥。启用后，AI 在本机独立线程搜索，先准备合法候选，再逐层搜索。到时间预算后显示已有结果；可以提前结束。切到后台时会结束本次搜索，保留已有建议。系统挂起、锁屏或资源不足时不能保证严格实时。AI 次数开始即扣除，刷新不退还。
休闲对弈规则
包含蹩马腿、塞象眼、炮隔子、九宫、过河兵、将帅照面及应将校验。将死、困毙判负，同一局面三次出现或达到 600 手判和。未实现正式竞赛长将、长捉裁决。
适用范围
适合朋友间休闲对战。两端校验走法和 AI 次数，但无法阻止修改程序或使用外部辅助。不依赖对战服务器，不上传棋局，不包含云端 AI。
同机对弈由双方轮流操作同一设备；AI 建议也会在屏幕上显示。
