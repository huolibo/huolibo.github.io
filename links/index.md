# 有趣的链接

平时收藏的优质工具、文章与资源，每条附一句话点评。

## 开发工具

- [VitePress](https://vitepress.dev/) —— 基于 Vite 的静态站点生成器，本站就用它搭建。
- [Obsidian](https://obsidian.md/) —— 本地优先的双链笔记软件，适合做知识管理。

## 学习资源

- [MDN Web Docs](https://developer.mozilla.org/) —— Web 技术权威文档，前端必备。
- [Battle-Tested Patterns](https://totoro-jam.github.io/battle-tested-patterns/) —— 收录 46 个来自 React、Linux、Go 等生产级代码库的「实战编程模式」，每个模式配有交互式可视化演示、精确到行的源码链接，以及 TypeScript / Rust / Go / Python 多语言实现和配套练习。本身也是用 VitePress 打造的优秀范例，本站的技术选型正是参考了它。

## 设计灵感

- [Coolors](https://coolors.co/) —— 快速生成配色方案的小工具。
